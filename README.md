# Underbeach

Piattaforma web per la gestione della relazione tra negozi e clienti nel settore beachwear e intimo.

## Funzionalita principali

- Registrazione e attivazione dei negozi.
- Dashboard amministrativa e area riservata negozio.
- QR personale per l'acquisizione clienti.
- Gestione clienti, consensi e comunicazioni.
- Catalogo prodotti e automazioni promozionali.
- Interfaccia responsive in italiano e inglese.

## Tecnologie

- Next.js e React
- TypeScript
- Supabase
- Vercel

## Avvio locale

```bash
npm install
npm run dev
```

La configurazione dell'ambiente e dell'infrastruttura e' riservata al team autorizzato e non viene distribuita nel repository pubblico.
